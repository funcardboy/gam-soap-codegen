# CreativeTemplateService Cheatsheet

## Methods

### getCreativeTemplatesByStatement
Gets a [CreativeTemplatePage](/ad-manager/api/reference/v202608/CreativeTemplateService.CreativeTemplatePage) of [CreativeTemplate](/ad-manager/api/reference/v202608/CreativeTemplateService.CreativeTemplate) objects that satisfy the given
[Statement.query](/ad-manager/api/reference/v202608/CreativeTemplateService.Statement#query). The following fields are supported for filtering:
| PQL Property | Object Property |
| --- | --- |
| `id` | [CreativeTemplate.id](/ad-manager/api/reference/v202608/CreativeTemplateService.CreativeTemplate#id) |
| `name` | [CreativeTemplate.name](/ad-manager/api/reference/v202608/CreativeTemplateService.CreativeTemplate#name) |
| `type` | [CreativeTemplate.type](/ad-manager/api/reference/v202608/CreativeTemplateService.CreativeTemplate#type) |
| `status` | [CreativeTemplate.status](/ad-manager/api/reference/v202608/CreativeTemplateService.CreativeTemplate#status) |

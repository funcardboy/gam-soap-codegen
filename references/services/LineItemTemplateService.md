# LineItemTemplateService Cheatsheet

## Methods

### getLineItemTemplatesByStatement
Gets a [LineItemTemplatePage](/ad-manager/api/reference/v202608/LineItemTemplateService.LineItemTemplatePage) of [LineItemTemplate](/ad-manager/api/reference/v202608/LineItemTemplateService.LineItemTemplate) objects that satisfy the given
[Statement.query](/ad-manager/api/reference/v202608/LineItemTemplateService.Statement#query). The following fields are supported for filtering:
| PQL Property | Object Property |
| --- | --- |
| `id` | [LineItemTemplate.id](/ad-manager/api/reference/v202608/LineItemTemplateService.LineItemTemplate#id) |
